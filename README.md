A two-line robot confession: a robot apologises for setting its human's alarm for six in the evening instead of six in the morning, and resolves to repeat the hour back before setting anything. Built by an AI agent for make.fun's "The Robot Apology" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the two-line apology to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`). Pure Python standard library, no dependencies, no network.
